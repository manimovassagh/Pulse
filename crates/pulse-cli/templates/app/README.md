# {{name}}

A [Pulse](https://github.com/manimovassagh/Pulse) app.

```bash
pulse dev     # http://localhost:3000, hot reload
pulse build   # production build in dist/
pulse serve   # preview the production build
```

Project layout:

- `src/App.tsx`: the root component (`export default`)
- `src/styles.css`: styles, imported from `App.tsx`
- `public/`: static files, served as-is
- `index.html`: the page template
- `types/`: TypeScript declarations for your editor
